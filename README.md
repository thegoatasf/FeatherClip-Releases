# Feather Clip downloads

[Download the latest version](https://github.com/thegoatasf/FeatherClip-Releases/releases/latest)

- **Windows:** download `FeatherClip-Windows-Setup.exe`, run it, and follow setup. It installs for your Windows account, adds a Start menu shortcut, and includes an uninstaller. Quit Feather Clip from its tray menu before upgrading.
- **Mac (Apple Silicon):** download `FeatherClip-Mac-AppleSilicon.dmg`, open it, and drag **Feather Clip** to **Applications**. For updates, quit the old app first and choose **Replace**. macOS 15 or newer is required.

Both apps check this repository for newer stable versions at startup. **Check for updates** is also in the Windows tray menu and Mac app/menu-bar menus. Downloads are checked against the release's SHA-256 checksums before opening. Windows launches setup; Mac opens the DMG for drag-and-drop replacement. Updates never silently replace a running app.

Saved clips and settings are preserved during upgrades and Windows uninstall. Uninstalling does not remove your saved clips.

These preview installers are not publisher-signed/notarized. Operating systems may show an unknown-publisher warning. The Mac app needs Screen & System Audio Recording permission, plus Microphone permission when enabled. Live capture on the newest macOS still needs interactive testing.

This public repository contains release infrastructure and binary installers. Application source remains private. GitHub's generated source archives contain only this download repository, not the app source.
